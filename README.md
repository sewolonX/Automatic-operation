# Automatic-operation 🎯

[油猴脚本（Tampermonkey）](https://www.tampermonkey.net/) — 在任意网页上自动操作（点击 / 填充）元素。

## ✨ 功能特性

- **可视化选取** — 鼠标悬停高亮，点选目标元素，所见即所得
- **智能识别** — CSS 选择器 + 元素指纹（标签、文本、id、class、属性、onclick）多重匹配，刷新页面后自动找回元素
- **10 套独立配置** — 编号 ① ~ ⑩，每套配置独立保存目标与参数，一键切换
- **多选模式** — 支持选取多个目标元素，可拖拽排序（↑↓ 箭头）
- **操作策略** — 同时操作（0ms 间隔）或队列操作（依次点击）
- **元素详情面板** — 点击 ⓘ 滑出详情面板，逐项控制匹配规则
- **逐项匹配开关** — 标签 / 文字（完全/模糊）/ id / class / 标准属性 / data-* 属性 / onclick / 父容器，每项独立开关，留空不匹配
- **一键禁用元素** — 关闭后自动跳过（无延时），元素以灰色显示
- **自动发现同类元素** — 运行时自动扫描父容器中新增的匹配元素，可独立开关
- **自动填充** — 自动检测输入框 / 文本框，填入预设内容
- **自动刷新** — 定时刷新页面，支持 10s ~ 24h 间隔，带实时进度条
- **自动启动** — 设置定时自动开始操作，循环执行，支持倒计时显示
- **最长时间限制** — 设定运行时长上限（支持小数分钟），到时自动停止
- **省电模式** — 全屏黑色遮罩，随机位置显示时间 / 运行时长 / 操作次数
- **屏幕常亮** — 调用 Wake Lock API 防止屏幕休眠
- **禁止聚焦** — 阻止页面元素抢焦点，避免中断自动操作
- **选取放行点击** — 拾取模式下可选择是否阻断页面自身的点击事件
- **元素消失处理** — 可配置「等待重试」或「立即停止」
- **暗色 / 亮色主题** — 自动跟随浏览器 / 网页主题切换
- **面板拖拽 & 折叠** — 鼠标/触屏拖拽移动位置，一键折叠为迷你状态栏
- **面板自动透明** — 选取元素时/折叠 1s 后面板自动半透明（opacity 0.65），点击面板恢复不透明，2s 后再次透明，渐变过渡 0.4s
- **自适应高度** — 面板高度随内容自动伸缩（上限 65vh），页面切换带平滑过渡
- **MiSans VF 字体** — 小米可变字体，全局统一排版（加载失败自动回退 system-ui）
- **数据持久化** — 所有配置自动保存至 localStorage，按域名隔离，刷新不丢失
- **跨页面状态恢复** — 刷新后自动恢复自动刷新 & 运行状态

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. [点击安装脚本](https://sewolon.oss-cn-shanghai.aliyuncs.com/automatic-operation/Automatic-operation.js)
3. 打开任意网页，左上角出现 **自动操作** 面板（初始为折叠状态）

## 🖥️ 界面概览

面板分为三个页面，通过底部的 `<` `>` 按钮切换：

| 页面 | 内容 |
| --- | --- |
| **第 1 页（操作）** | 多选模式开关、操作策略、目标元素列表、自动填充 |
| **第 2 页（参数）** | 操作次数、操作时间、操作间隔、自动启动、元素消失处理 |
| **第 3 页（系统）** | 自动刷新、省电模式、屏幕常亮、禁止聚焦、选取放行、面板字体 |

**标题栏**包含：折叠按钮 `−/+`、开始/停止按钮 `▶/■`、面板标题、配置切换按钮 `①~⑩`。

**底部状态栏**显示：已操作次数、运行计时、当前状态文字。

## ⚡ 详细教程

### 一、基础用法 — 单目标自动点击

1. 点击面板底部的 **选取元素** 按钮（按钮变为橙色脉冲「取消选取」）
2. 鼠标移至页面目标元素上，元素会显示**虚线高亮框**
3. 点击目标元素完成选取 — 元素显示**绿色实线框**，面板自动退出选取模式
4. 切换到第 2 页，配置参数：
   - **操作次数**：留空 = 无限点击
   - **操作间隔**：每次点击的间隔（默认 1000ms）
5. 点击底部的 **开始** 按钮（或标题栏的 ▶ 按钮），脚本开始自动点击
6. 点击 **停止** 按钮结束运行

### 二、多选模式

适用于需要操作多个不同元素的场景。

1. 在第 1 页开启 **多选模式**
2. 选择操作策略：
   - **同时操作** — 每个间隔同时点击所有目标
   - **队列操作** — 按列表顺序逐个点击，每次一个
3. 点击 **选取元素**，依次点选多个目标（每点一个自动加入列表）
4. 在目标列表中使用 **↑↓** 按钮调整顺序（队列模式下的执行顺序）
5. 点击 **开始** 运行

> 多选模式下，每个目标元素旁显示序号；队列模式下状态栏显示当前队列进度。

### 三、元素详情面板与匹配规则

点击目标元素右侧的 **ⓘ** 按钮，从右侧滑出详情面板。所有修改**即时生效并自动保存**。

#### 3.1 匹配规则一览

| 规则 | 说明 |
| --- | --- |
| **启用此元素** | 总开关，关闭后自动跳过，元素显示为灰色 |
| **标签匹配** | 匹配 HTML 标签名（如 `div`、`button`） |
| **文字匹配** | 匹配元素文本内容，支持**完全匹配** / **模糊匹配**（包含即匹配） |
| **id 匹配** | 匹配元素 `id` 属性 |
| **class 匹配** | 匹配元素 `class` 属性（包含所有指定类名即匹配） |
| **标准属性匹配** | 匹配 `href`、`src`、`value`、`type`、`name`、`role`、`alt`、`title`、`placeholder`、`action`、`method` 等属性 |
| **data-\* 属性匹配** | 匹配所有 `data-*` 自定义属性 |
| **onclick 匹配** | 匹配 `onclick` 属性中的 `useItem(N)` 调用参数 |
| **父级容器匹配** | 限定在指定父容器内查找，避免误匹配页面其他位置 |
| **自动发现同类** | 运行时自动扫描父容器中新增的匹配元素并加入操作列表 |

#### 3.2 匹配规则组合逻辑

所有**开启的规则必须全部满足**才算匹配成功。合理组合可实现精确定位：

- 只开**标签 + 文字** → 匹配相同标签且文字相同的元素
- 只开**data-* 属性** → 匹配具有相同 `data-id` 等自定义属性的元素
- 全部关闭（仅保留 CSS 选择器） → 仅靠选择器匹配

> **留空 = 不匹配该项**：属性值留空时，只要元素**存在该属性**即视为匹配。

#### 3.3 测试功能

详情面板顶部有 **测试** 按钮，点击后：

- 在页面上用**粉色虚线框**高亮所有匹配到的元素
- 每项规则旁显示 `✓ 数量`（绿色）或 `✕`（红色）
- 可直观验证匹配范围是否正确

### 四、自动填充（输入框操作）

当选取的目标元素是输入框（`<input>`、`<textarea>`、`contentEditable`）时：

1. 第 1 页自动显示 **自动填充内容** 输入框
2. 填入要填充的文字
3. 运行时脚本将**填入内容**而非点击元素
4. 同时触发 `input` 和 `change` 事件，兼容大多数前端框架

### 五、自动刷新

切换到第 3 页：

1. 开启 **自动刷新网页**
2. 设置刷新间隔（10s ~ 86400s，即 10 秒到 24 小时）
3. 面板显示**实时进度条**，包含百分比和剩余时间
4. 刷新前自动保存所有状态，刷新后自动恢复：
   - 正在运行的配置会继续运行
   - 自动刷新计时器继续
   - 省电模式保持
5. 刷新日志记录每次刷新的时间和状态

> 进度条在剩余 < 30s 时变为红色，提示即将刷新。

### 六、自动启动

第 2 页的 **自动启动** 功能：

1. 填入间隔分钟数（支持小数，如 `1.5` = 1分30秒）
2. 标签旁显示**实时倒计时**
3. 时间到后自动开始操作，操作结束后重新计时循环
4. 如果目标为空，跳过本次启动并继续倒计时
5. 手动停止运行后，倒计时重新开始

### 七、省电模式

第 3 页开启，或运行时自动启用：

- 全屏黑色遮罩覆盖页面
- 四个元素随机分布并定时移动：
  - **当前时间**（大号字体）
  - **运行时长**
  - **已操作次数**
  - **开关按钮**（可关闭省电模式）
- 自动尝试进入全屏模式
- 退出全屏自动关闭省电模式

### 八、配置管理（10 套独立配置）

面板标题栏右侧显示当前配置编号 **① ~ ⑩**：

- 点击弹出下拉菜单，选择切换配置
- 每套配置**完全独立**存储：
  - 目标元素列表
  - 操作策略和参数
  - 匹配规则设置
- 当前正在运行的配置显示**绿色圆点**标记
- 切换配置时自动保存当前配置

### 九、面板操作

| 操作 | 方法 |
| --- | --- |
| **拖拽面板** | 鼠标/触屏按住标题栏空白区域拖动 |
| **折叠/展开** | 点击标题栏 `−` / `+` 按钮 |
| **切换页面** | 点击底部 `<` `>` 按钮 |
| **清空目标** | 点击目标列表上方的 **清空** 按钮 |
| **删除单个目标** | 点击目标元素右侧 `✕` 按钮 |
| **查看详情** | 点击目标元素右侧 `ⓘ` 按钮 |
| **返回列表** | 详情面板点击 `<` 返回按钮 |

#### 面板透明度行为

- **选取元素时**：面板立即半透明（opacity 0.65），避免遮挡页面内容
- **折叠后**：1 秒后面板自动半透明
- **点击面板任意位置**：恢复不透明，2 秒后再次自动半透明
- **退出选取 / 展开面板**：恢复完全不透明
- 渐变过渡时间：0.4 秒

## 🛠️ 技术细节

- **纯 JavaScript**，无外部依赖（字体 CDN 除外）
- 使用 `localStorage` 按域名隔离存储，配置键 `AUTO_OP_CFG_<hostname>_<0~9>`
- **元素匹配**：CSS 选择器（初次）+ 元素指纹（标签名、文本、id、class、data 属性、关键属性、onclick）双重定位
- **查询缓存**：`beginQueryCycle()` 创建缓存，同一 tick 内复用 `querySelectorAll` 结果，减少 DOM 查询
- **UI 节流**：运行时 UI 更新限制 100ms 间隔，避免高频刷新
- `ResizeObserver` 动态调整面板高度
- 拖拽支持鼠标 + 触屏（主面板 + 详情面板头部）
- 省电模式使用 `requestFullscreen` + `setInterval` 定时随机位置刷新
- **状态恢复**：刷新前将运行状态写入 `localStorage`（`REFRESH_STATE_KEY`），刷新后读取恢复
- 暗色/亮色主题通过 `MutationObserver` 监听 `<html>` 和 `<body>` 的 class/style 变化

### 存储键一览

| 键 | 内容 |
| --- | --- |
| `AUTO_OP_SHARED_<host>` | 全局共享状态（自动刷新、省电模式、面板字体等） |
| `AUTO_OP_CFG_<host>_<0~9>` | 每套配置的目标列表和参数 |
| `AUTO_OP_REFRESH_STATE_<host>` | 刷新前的临时状态（用于跨刷新恢复） |

### 元素指纹结构

```js
{
  tagName: 'button',       // HTML 标签名
  text: '提交',            // 元素文本内容
  id: 'submit-btn',        // id 属性
  className: 'btn primary', // class 属性（过滤后）
  dataAttrs: {             // data-* 属性
    'data-id': '123'
  },
  attrs: {                 // 关键标准属性
    'href': '/api/submit',
    'type': 'button'
  },
  onclickParam: '42',      // useItem(N) 的参数
  hasStrong: true          // 是否有 id / data-* / 关键属性
}
```
