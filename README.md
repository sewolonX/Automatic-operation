# Automatic-operation 🎯

[油猴脚本（Tampermonkey）](https://www.tampermonkey.net/) — 在任意网页上自动操作（点击 / 填充）元素。

## ✨ 功能特性

- **可视化选取** — 鼠标悬停高亮，点选目标元素，所见即所得
- **智能识别** — 通过 CSS 选择器 + 元素指纹（标签、文本、属性）双重匹配，刷新页面后自动找回元素
- **10 套独立配置** — 编号 ① ~ ⑩，每套配置独立保存，一键切换
- **多选模式** — 支持选取多个目标元素
- **操作策略** — 同时操作（0ms 间隔）或队列操作（依次点击）
- **自动填充** — 自动检测输入框 / 文本框，填入预设内容
- **自动刷新** — 定时刷新页面，支持 10s ~ 24h 间隔，带进度条
- **自动启动** — 设置定时自动开始操作，循环执行
- **最长时间限制** — 设定运行时长上限，到时自动停止
- **省电模式** — 全屏黑色遮罩，随机分布显示时间 / 运行时长 / 操作次数
- **屏幕常亮** — 调用 Wake Lock API 防止屏幕休眠
- **禁止聚焦** — 阻止页面元素抢焦点，避免中断自动操作
- **元素消失处理** — 可配置「等待重试」或「立即停止」
- **暗色 / 亮色主题** — 自动跟随浏览器 / 网页主题
- **面板拖拽 & 折叠** — 可拖拽移动位置，一键折叠为迷你状态
- **数据持久化** — 所有配置自动保存至 localStorage，刷新不丢失
- **跨页面状态恢复** — 刷新后自动恢复运行状态

## 📥 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. [点击安装脚本](https://sewolon.oss-cn-shanghai.aliyuncs.com/automatic-operation/Automatic-operation.js)
3. 打开任意网页，左上角出现 **自动操作** 面板

## ⚡ 快速上手

### 基础用法

1. 点击 **选取元素** 按钮，鼠标移至页面目标元素上（会高亮显示）
2. 点击目标元素完成选取
3. 配置操作次数、间隔等参数
4. 点击 **开始** 按钮，脚本自动执行点击

### 多选模式

1. 在面板第 1 页开启 **多选模式**
2. 选择操作策略：

   - **同时操作** — 所有目标同时点击
   - **队列操作** — 按选取顺序依次点击

3. 依次点选多个目标元素
4. 点击开始

### 自动填充

选取的目标元素为输入框 / 文本框时：

1. 面板会自动显示 **自动填充内容** 输入框
2. 填入内容后开始运行，脚本将自动填写而非点击

### 自动刷新

切换到第 3 页：

1. 开启 **自动刷新网页**
2. 设置刷新间隔（秒）
3. 脚本按间隔刷新页面，刷新后自动恢复运行状态

### 配置切换

点击面板标题栏右侧的配置编号按钮（①~⑩），可快速切换不同配置。每个配置的目标元素和参数完全独立。

## 🎛️ 配置说明

| 配置项             | 说明                                                               |
| ------------------ | ------------------------------------------------------------------ |
| **操作次数**       | 留空 = 无限；填入数字限制点击次数                                  |
| **操作时间 (min)** | 最长运行时长，支持小数（如 1.5 = 1分30秒），到时自动停止           |
| **操作间隔 (ms)**  | 每次操作的间隔时间，默认 1000ms                                    |
| **自动启动 (min)** | 设置定时自动开始，支持小数；留空 = 关闭                            |
| **元素消失后**     | `等待重试` 自动继续 / `立即停止`                                   |
| **严格 / 宽松**    | 每个目标可切换匹配模式：严格匹配所有属性，或只匹配文本内容         |

## 🛠️ 技术细节

- **纯 JavaScript**，无外部依赖
- 使用 `localStorage` 按域名隔离存储
- CSS 选择器 + 元素指纹（标签名、文本、data 属性、关键属性）双重匹配
- `querySelector` 缓存机制减少 DOM 查询开销
- `ResizeObserver` 动态调整面板高度
- 拖拽支持鼠标 + 触屏
- 省电模式使用 `requestFullscreen` + 定时随机位置刷新
